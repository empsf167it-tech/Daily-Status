☁️ Real-time Cloud Database Sync

Local Storage Mode

Connect this website to Firebase Realtime Database so that developers and testers in any location can submit their attendance and work entries, and everyone can view updates live in real time!

⚡ 2-Minute Free Cloud Setup:
  1. Visit Firebase Console and click Create a project.
  2. In the left menu, select Build > Realtime Database > click Create Database.
  3. Choose Start in test mode (so read/write rules are allowed).
  4. Copy your Database URL (e.g. https://your-project-default-rtdb.firebaseio.com) or your Web App Config and paste below.
👥 Multi-User Team Sharing: Once connected, click "Copy Team Link" below and share the link with your team. Anyone opening the link will be automatically connected to this database!
